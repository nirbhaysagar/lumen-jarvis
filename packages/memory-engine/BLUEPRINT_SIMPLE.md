# Lumen + Sheldon — Plain-Language Blueprint (no tech)

> One-line: **Dump anything. It remembers properly. Ask anything. It answers with your full context.**

- **Lumen** = the brain that stores and maintains memory.
- **Sheldon** = the app you see and touch.

---

## 1. The problem it solves

Your knowledge is scattered: ChatGPT chats, Claude chats, Slack, Notion, docs, PDFs, emails, notes in your head.

Every time you start a new AI chat you have to re-explain everything. Smart AI + bad context = generic answers.

This tool fixes that: one place holds your context, any AI can use it.

## 2. The pain we remove

- Re-pasting "Orbit launches in Oct, $29/mo, 500-user goal" 20 times → paste once, it stays fresh.
- ChatGPT knows one half, Claude knows the other → one brain both can use.
- Old news haunts you ("Sept launch" cited after you moved to Oct) → old stuff is kept as history, only current truth is answered.
- Contradictions ("Sept / Oct / indefinite") → it picks a clear winner or asks you to confirm. Nothing silently overwritten.
- 10 random chunks → a clean answer pack: goal + current state + feedback + conflicts.
- "Where did this come from? Can I delete it?" → every memory shows its source; delete works everywhere.
- Great answers lost in chat scroll → home shows saved knowledge first; chat is just one small box.

## 3. What the tool does

**Dump side:** throw in thoughts, ideas, summaries, emails, files, later voice notes and pictures. Pick a workspace (Orbit, Research, Personal). Done — it labels, files, and connects everything by itself.

**Ask side:** type a question in Sheldon, or ask from Slack / ChatGPT / your coding tool. It pulls only what matters right now and answers with proof (what + where it came from + what changed).

Example: "Should we change pricing?" → answers with: current $29, goal 500 users, 3 users say OK, 2 want free tier, rule "no enterprise pricing yet" — then a recommendation.

## 4. All features (plain)

1. **Dump box** — paste / upload / forward anything into a workspace.
2. **Auto-labels** — each memory tagged: fact, decision, goal, assumption, question, idea, rule, to-do, preference + how sure it is.
3. **Smart templates** — research, decisions, plans, client work each get the right shape (e.g. decision = problem / options / choice).
4. **No duplicates** — same thing twice = one card.
5. **Workspaces that don't leak** — Research never pollutes Coding. Cross-workspace links are shown as "related, not authoritative."
6. **Time-aware** — Sept → Oct keeps both; Oct is current, Sept is history with a timeline.
7. **Conflict check** — clear win auto-updates; close call goes to you: "Keep Oct? [Yes / Keep both]".
8. **Connections** — Orbit links to launch, price, goal, audience. Limited so it never becomes spaghetti.
9. **Teach it** — edit any card → it gets a star, ranks higher, becomes Trusted faster.
10. **Ask Brain** — one box; answers with Recent + Trusted + Related + Conflicts + what needs your review.
11. **Search + Collections** — home is knowledge, not chat. Search everything, group, pin the important.
12. **Sources + delete** — every card shows origin; delete one card or a whole source, gone everywhere.
13. **Works everywhere** — same brain in Sheldon, Slack, coding tool, ChatGPT. Swap models without losing memory.

## 5. How you use it (a normal day)

- **Morning (30 sec):** dump yesterday's notes / forward an email / upload a doc. Pick workspace. Forget organizing.
- **Working:** open Sheldon → see Collections + Knowledge. Search "Orbit pricing" → current truth on top, history one click away.
- **Deciding:** Ask Brain "Should we change pricing?" → read grounded answer with citations → your new decision auto-saves.
- **When things change:** say "launch moved to Nov" → timeline updates, old date kept as history. If unclear, confirm once in Review (weekly, 2 min).
- **With team (later):** connect Slack/Notion once → shared team brain; everyone + every bot pulls from it.

## 6. Build phases (plain)

- **Phase 0 DONE:** brain core works — dump, label, dedupe, Sept→Oct update, isolated workspaces, starred edits, answer packs.
- **Phase 1 (next):** smarter reading (AI understands messy notes/PDFs), web app v1 (search, collections, Ask box, Review list, edit-stars), quality checks.
- **Phase 2:** connections — import ChatGPT/Claude chats, Notion/Slack pull, copy-answer button everywhere; browser saver only after people actually save daily.
- **Phase 3:** team + platform — shared workspaces, permissions, Slack/coding bots, paid access for other apps.
