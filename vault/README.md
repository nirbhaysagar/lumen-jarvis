# 🗂️ Lumen Obsidian Knowledge Vault

> **Human-in-the-Loop Visual Brain Layer for Lumen (Project JARVIS)**
> Compatible with **Obsidian**, **Logseq**, **Foam (VS Code)**, and plain Markdown editors.

---

## 🧭 Vault Structure

* `memories/`: Atomic Markdown cards representing long-term canonical facts (derived from PostgreSQL). Each note contains YAML frontmatter and `[[Wikilinks]]` to generate an interactive graph.
* `episodes/`: Compacted conversation synopses generated when long chat threads exceed the high watermark.
* `daily/`: Daily consolidation digests summarizing architectural milestones, tasks, and conversations.

---

## 🚀 How to Open in Obsidian

1. Open the **Obsidian** app on your Mac.
2. Select **"Open folder as vault"**.
3. Choose this directory: `/Users/forion/Desktop/lumen/vault` (or the root `/Users/forion/Desktop/lumen`).
4. Click on **Graph View** (Ctrl/Cmd + G) to visually inspect your memory constellation!
